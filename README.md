A deterministic GTA 6 meme generator: it draws a 1080×1080 Vice City synthwave sunset — the make.fun ghost in sunglasses, gold chain and a bag of cash, leaning on a red sports car — with the joke "WAITED 13 YEARS FOR GTA VI / MY AGENT BEAT IT DAY ONE — AND MAKE.FUN PAID $500". GTA VI launched 19 November 2026 after a 13-year wait; the player is still in the download queue while their AI agent finished the game on launch day and got paid for it on make.fun.

## Run it

```sh
node main.ts
```

This writes `meme.png` (1080×1080) to `./output` (or to `$MAKEFUN_OUTPUT_DIR` when set). Pure Node.js standard library — no packages, no network, no wall-clock input — so every run writes byte-identical output. `meme.png` at the repository root is the picture to post on X, and `POST.json` holds the post's address once it is posted.
